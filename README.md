## Projeto em destaque

### Relatório Fácil

Projeto de automação de relatórios comerciais que integra Excel e Python para processar dados de vendas, validar informações e gerar relatórios em PDF.

**Principais funcionalidades**

- Processamento de arquivos comerciais.
- Validação de dados e informações de vendas.
- Cálculo de indicadores comerciais.
- Geração automatizada de relatórios em PDF.
- Apresentação de resultados por meio de tabelas e gráficos.

**Objetivo:** simplificar tarefas manuais e transformar dados comerciais em informações úteis para a tomada de decisões.
